Plume Pages Documentation

v0.3.0

1.Global mechanisms

1.1Paginations

Rendering splits the body into fixed-size pages that match the page format (size and margins).
An element that does not fit moves whole to the next page — it is never split across pages.
Page breaks are driven by CSS fragmentation properties:
→break-before: page starts a new page (newpage is the ready-made marker)
→break-after: page makes the following content start on a new page
→break-after: avoid keeps the element with the next one (no orphan heading)
.pages--page is generated by the engine — never add it manually or pagination is skipped.

1.2Paragraphs

Runs of inline content are auto-wrapped in p by a JS pass, in the body and in every nested flow container (.pages--to-flow).
A block element ends the paragraph; $par forces a paragraph break.
A display formula is marked .pages--as-inline so it stays in its sentence, and pagination never splits them.
Plume strips blank lines, so two paragraphs of plain text joined by a blank line are concatenated. Separate them with $par.

1.3Spacing

Block components meant to be followed by flexible space carry .pages--to-space — headings, hline, Blockquote, MainTitle.
A JS pass inserts a bounded spacer before each .pages--to-space and as the last element of every page, absorbing leftover space up to --vspace-max.
Manual spacers: hspace (horizontal), vspace (bounded), vfill (fills the page).

1.4Numbering Format

Headings and ordered lists number automatically from per-level counters.
The format is a string over a few tokens:
→1 decimal, a and A lowercase and uppercase letters, i and I roman numerals
→* renders the parent level (forbidden at level 1)
Compose tokens freely, e.g. a., 1, *.1.
The default per level is set by the contextual variables formatNumbering1 to formatNumbering6.

2.4List

macro List

Usage: List (Number indent: 4, Number columns: 1, marker:, rawmarker:,...items)

Bulleted or numbered list.
To choose the bullet, set marker to bullet, star, arrow, dash, cross, check or a custom one.
To make an ordered List, set marker to auto or use Numbering Format.
If marker value is interpreted but shouldn't be, use rawmarker instead.
indent sets the left padding.

2.5MainTitle

macro MainTitle

Usage: MainTitle (title:, subtitle:, author:, date:, institution:)

Intended to be on first page or used as cover
By default, put title - subtitle - author one below the other, and date/institution on one line and smaller.
All fields are optionnals.

2.6Math

macro formula

Usage: formula (content, processor:, ?display)

Rendering a math formula
processor could be tex (for LaTeX syntax) or ascii (for asciimath syntax). If empty, use contextual variable formulaProcessor.
?display renders it as a block.

2.7Table

macro Table

Usage: Table (?zebra, ...rows)

Make a table from a List of Lists
You can provide an header key with the first row as value.
?zebra alternates row colors.
Example: 
@Table
    header: (id, name, price)
    - (1, Apple, 2€)
    - (2, Orange, 3€)
end
